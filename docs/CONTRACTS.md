# 模块接口契约（子代理必读）

为了并行迁移时不互相踩接口，所有跨模块调用按这里的签名实现。
参数名尽量与旧代码一致；返回 dict 的形状也保持一致。

## agent

```python
# agent/runtime.py
class QQBotAgent:
    def __init__(self, *, api=None, messaging=None, media=None, images=None,
                 settings=None, llm_config: dict | None = None): ...
    async def chat(self, event=None, context=None, thread_id=None,
                   user_message=None, extra_context=None) -> list[str] | None: ...
    async def maybe_interject(self, context, thread_id, reason="") -> list[str] | None: ...
```

工具内可用的对象：
- `self.api`：OneBot API（poke / emoji_like / ban / recall / get_message）
- `self.messaging`：发送消息、历史、上下文
- `self.media`：OCR、B 站、点歌
- `self.images`：`resolve` / `to_backend`（旧名 `to_napcat`）/ `dress`
- `self.settings`：`master_qq` / `agent_*` / `prompt` / `reply`
